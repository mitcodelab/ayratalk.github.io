  1. The initial PIN is 123456. Unlock with it, then choose a new PIN in Settings.
  2. Copy a standard board or create a board from a routine template.
  3. Try text to speech and any uploaded recordings.
  4. Install this page from the phone browser menu, then confirm it opens in airplane mode.
  5. Export a backup and keep it somewhere you can find later.

🔏 Privacy Notice

What data is stored?

  • Communication boards and custom tiles you create.
  • Optional on-device usage trends and a short Recent list. Turn trends off under Feel to stop recording new tile taps.
  • Saved quick phrases and favorites.
  • Settings (theme, volume, speed, mode, voice, shortcuts).
  • Audio clips and the voice sample (browser IndexedDB on this device).
  • The caregiver PIN, stored as a one-way hash.

Where is it stored?

Boards and settings stay in this browser (localStorage and IndexedDB). The optional Support screen can open a service selected by you. A web-chat handoff copies your reviewed text to the clipboard; SMS places it in a phone draft. The app does not send it automatically. Once you paste or send it in the external service, that service's privacy practices apply. The page's security policy blocks background network requests.

Backups

Export saves everything above except the PIN into one file. Keep that file private.

How to delete?

Use Restore Defaults above to erase all stored data. You can also clear this site's data in your browser settings.

Device sharing notice

Data is visible to anyone with access to this device and browser. Lock the app when not in use to prevent unintended changes. The PIN stops casual changes; it is not strong security.

iPad and iPhone

Add TalkBoard to the Home Screen. Safari can delete website data after 7 days without a visit, so also export a backup regularly.

TalkBoard has not been formally assessed against privacy laws such as GDPR, HIPAA or the Australian Privacy Principles. Keeping data on the device supports their principles; compliance depends on how the app is used.

Using TalkBoard on a phone

Install from your browser menu: on iPhone, use Safari → Share → Add to Home Screen. On Android, use Chrome → menu → Install app or Add to Home screen. Open once while online so the app and pictures can be cached, then try airplane mode. Export a backup before clearing browser data or moving to another phone.
